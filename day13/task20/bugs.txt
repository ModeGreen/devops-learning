В функции find_alerts return стоял в теле цикла - функция возвращала итоговый список alerts после обработки первого маунта. Убрал лишний таб, чтобы выполнялась после завершения цикла.
В функции get_tresholds значение из переменной окружения приходило в формате str. Это вызывало ошибку при сравнении с процентом заполненности маунта. Добавил конвертацию в int.
В функции main при вызове load_disks() except не ловил json.decoder.JSONDecodeError (битый json файл). Добавил эту ошибку в кортеж к except.
